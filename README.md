# 🍲 搶火鍋大作戰

跟女朋友一起吃火鍋，但每一塊肉都是戰場！
這是一款 HTML5 小品遊戲：搶在她之前夾到「剛好熟」的食物，同時別把她惹毛。遊戲沒有終點，會越來越難，每局結束都能拿到「飯票」去商店升級。

## 怎麼玩

- **點鍋裡的食物**：伸筷子去夾。食物外圈的顏色代表熟度：
  - 藍色：生的（吃了會肚子痛，要扣分）
  - 綠色：剛好（分數最高，連續夾到還有連擊加成）
  - 咖啡色：煮太老（分數很低，放太久會消失）
- **粉紅虛線圈**：她正在瞄準的食物，先夾到的人贏。
- **她會打掉你的食物**：你夾著食物回碗的路上，她可能出筷打你。看到 ❗ 時**點一下畫面**就能閃開。太早亂點會手抖，閃不掉。
- **怒氣值**：搶她瞄準的食物或她「指定」的食物，怒氣會飆高；讓她吃到東西（尤其是她最愛的）會消氣。
- **飽足感**：會一直下降，要記得吃東西。
- **遊戲結束**：她的怒氣滿了，或你的飽足感歸零。
- **每 30 秒一波**：她會越來越快，還會假動作。後期會出現蒸氣遮住視線、辣鍋（食物熟得更快）、她指定食物等干擾。每波開始時會有稀有食材（和牛、龍蝦、帝王蟹、生蠔）下鍋。

### 商店

- **永久能力**：筷子速度、夾取範圍、大胃王、好脾氣、握力、飯票加成（各 6 級）
- **道具**（遊戲中點下方按鈕使用）：
  - 🥢 公筷：5 秒內出筷加倍快、必搶贏、不會被打掉
  - 🥺 撒嬌：怒氣立刻 -35
  - 🍲 加湯：過熟的食物變回剛好，8 秒內熟得比較慢
  - 📱 手機訊息：她分心滑手機 5 秒

### 電腦操作

滑鼠點擊；空白鍵閃避；1～4 使用道具；Esc 或 P 暫停。

## 在本機開啟

不需要安裝任何東西，直接用瀏覽器打開 `index.html` 就能玩。
也可以直接部署到 GitHub Pages（所有路徑都是相對路徑）。

存檔放在瀏覽器的 localStorage，換瀏覽器或清除網站資料會重置進度。

## 檔案結構

```
index.html      頁面與各個介面（選單、商店、說明、暫停、結算）
css/style.css   介面樣式
js/config.js    所有數值：食物、難度曲線、升級、道具、飯票、台詞
js/save.js      存檔讀寫（讀到損毀資料會自動重置）
js/audio.js     WebAudio 即時合成音效
js/game.js      一局的遊戲邏輯：熟度、女友 AI、打掉與閃避、怒氣、飽足、事件、道具
js/render.js    Canvas 繪圖：鍋子、食物、女友表情、筷子、HUD、特效
js/ui.js        DOM 介面：選單、商店、結算
js/main.js      進入點：畫面縮放、輸入、主迴圈
```

想調整難度或經濟，改 `js/config.js` 就可以。
